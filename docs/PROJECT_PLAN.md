# Project Plan

## Goal

Build a lightweight device security and health monitor for Linux kiosks, signage players, Raspberry Pi devices, and edge systems.

## MVP

- Collect local or sample device telemetry.
- Analyze CPU, memory, heartbeat, process, network, and USB signals.
- Generate alerts with severity, evidence, and recommended next steps.
- Produce dashboard-ready summary JSON.
- Produce Markdown report and alert timeline for portfolio demos.

## Deep Polish Scope

- Add risk scoring and severity counts.
- Add recent reboot and unusual outbound connection detection.
- Add Docker demo workflow.
- Replace placeholder docs with architecture and safety notes.
- Expand tests around dashboard and timeline outputs.
