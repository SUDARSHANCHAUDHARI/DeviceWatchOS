# DeviceWatch OS

**Goal:** Security and health monitoring for remote devices.

**MVP:** Agent sends device metrics to dashboard.

## Core Features

- device heartbeat
- reboot tracking
- CPU/RAM/network usage
- suspicious process detection
- USB event detection
- alert dashboard

## Suggested Stack

Python agent, FastAPI, React, PostgreSQL, Docker.
